# RhineLabUI 界面与流式稳定性

交付日期：2026-09-09。实现了此前优化方案的 P1：真实取消、可靠终态、批量持久化，并用本地 RhineLabUI 作为前端视觉参考。

## 界面

- 七个页面统一为暖灰背景、MiSans 字体、暖金强调色、细线与模块编号。重做主导航、状态栏、对话欢迎页、历史列表、消息排版和输入区；保留深色模式及已保存的主题选择。
- 工作台复用 `RhineLabUI/public/assets/archive-cassette.glb`，六个档案对应 AI 对话、CodeLens、Nebula、DevOps、Gateway、设置。支持点击档案、键盘操作前后按钮以及普通模块链接。
- Three.js 独立懒加载，仅在工作台且屏幕至少 900px、未启用减少动画时使用。选中动画完成后停止持续绘制；页面不可见时暂停，离开工作台释放 WebGL 资源。手机和减少动画模式使用静态档案；WebGL 不可用时仍能通过模块目录进入功能。
- 三维模块生产包约 599kB / gzip 154kB，构建保留大模块提示；已验证聊天首屏不请求该模块或模型资产。MiSans 四种字重均复用原版字体，约 19.7MB，字体许可和来源随包附带。
- 桌面 CSP 增加同源连接许可，使打包后的 GLB 可从应用本地资源加载。

## 请求生命周期

每次生成持有独立的 `requestId / sessionId / messageId`，运行时位于页面之外。阶段为上下文准备、等待模型、输出中，最终进入完成、已取消或失败；异常退出后恢复为中断。

1. 同步占用生成状态并插入消息占位，防止重复发送；准备上下文最多等待 8 秒。准备阶段取消不会提交模型请求。
2. Tauri 先注册请求 ID 再返回确认。前端快速停止会等待该确认后调用取消，避免取消先到达导致遗漏。
3. Rust 用可取消的异步 HTTP future 覆盖连接、等待首包及读取过程。取消后丢弃网络 future，释放注册信息；Go 从 HTTP 请求上下文感知断开，并中止上游与队列等待。
4. 前端立即保存已显示及缓冲的部分答案，拒绝已结束请求的所有后续回调。切换页面或会话保持原请求归属；删除来源会话会取消请求。
5. 原生窗口正常关闭前冲刷内容、保存并取消请求，失败时保留窗口并显示重试；窗口真正销毁时 Rust 再取消残留任务并结束后端进程。

当前全应用一次只生成一条回答。切到其他会话时显示返回生成会话的入口。浏览旧消息或搜索命中时不强制滚底。

## 协议与后端

| 事件 | 含义 |
| --- | --- |
| `token` | 有序增量文本 |
| `done + content + completed` | 最终完整文本，替换已累积文本，不再次追加 |
| `error + failed` | 生成失败，保留已收到的部分文本 |
| `cancelled` | 用户或窗口取消，由桌面桥接层发送终态 |

- 修复流式日志的无匹配解锁、最终正文重复、Gemini 一次返回正文被丢失等问题。
- Go 流式和普通调用共用并发预算，队列等待和上游请求均响应取消。日志追加、模型快照读取使用对应锁。
- OpenAI / Claude 必须收到明确结束标记；EOF 不再当成功。提供商向通道发送数据时同时监听取消。
- Rust 解析跨网络块 UTF-8、CRLF、多行 SSE 与旧版结束格式；畸形数据、超大事件和未结束即断流都会报告失败。每个请求最多发出一个终态。

## 保存

显示增量约每 32ms 合并；localStorage 保存约每 250ms 合并，JSON 序列化也在合并后执行。新消息、完成、取消、删除、页面隐藏和正常窗口关闭会立即冲刷。测试中连续提交 1,000 个保存快照，只序列化并写入最新一个。

存储写入失败保留最新待保存快照并显示重试。读取原始数据失败则暂停写入，避免空状态覆盖历史数据。保留原 `noosphere-chat-v1` 键及旧消息兼容性；只为消息增加可选状态字段。

硬崩溃或断电仍可能损失尚未写入的最后一批内容，正常情况下目标窗口约 250ms；系统繁忙、定时器受限或存储失败时可能更长。浏览器刷新可以同步保存，但无法保证异步取消 IPC 完成；生产桌面的正常关闭有等待流程。

## 复现

```powershell
# frontend，Node 24
pnpm test
pnpm build
pnpm dev --host 127.0.0.1
# 在另一终端；需要可用的 Playwright 包和 Edge
# 可通过 PLAYWRIGHT_MODULE 指定已有包路径，无须修改产品依赖。
pnpm test:ui
pnpm test:production

# backend
go test ./...

# desktop/src-tauri，Rust 1.88+，建议当前稳定版
cargo test --lib
cargo build
```

浏览器脚本支持 `QA_OUTPUT`、`QA_BROWSER`，交互回归还支持 `QA_URL`。默认截图和报告写入运行目录的 `qa-output`。历史搜索浏览器脚本和本次截图保存在任务的可视化输出目录；纯逻辑测试及新回归脚本在 `frontend/tests`。

本次 Windows 锁定依赖最高要求 Rust 1.88，已同步清单和 README。旧构建缓存与新工具链不兼容时，可指定独立 `CARGO_TARGET_DIR`；本次使用临时构建目录验证，未清除既有发布目录。
