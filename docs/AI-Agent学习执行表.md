## 四个阶段检查

### 第四周

- [ ] 我能独立遍历小目录并统计文件。
- [ ] 我能读写 JSON 并处理不存在的文件。
- [ ] 我能写正常和异常情况的测试。
- [ ] 我能解释 GET、POST、请求体、响应和 401。
- [ ] 我能独立完成一个小接口与调用脚本。

如果没有通过，先用一周巩固，再进入 Go 与项目链路。

### 第八周

- [ ] 我能画出聊天请求与返回路径。
- [ ] 我能解释取消为何必须传到后端。
- [ ] 我能读懂一个 Go handler 和业务函数。
- [ ] 我能说明请求和结果属于哪个会话、工作区与项目。
- [ ] 我能演示未变文件、注释变化与函数正文变化的差别。

### 第十二周

- [ ] 我能说明真实 embedding 与哈希向量的区别。
- [ ] 我能解释项目内检索的实际范围。
- [ ] 我能解释待确认记忆为何不参与上下文。
- [ ] 我能写一个有限预算的工具循环。
- [ ] 我能让未知工具、越界路径和重复调用被拒绝。
- [ ] 我能展示提案未执行、确认执行、冲突拒绝和条件恢复。

### 第十六周

- [ ] 我有一个由自己完成核心逻辑的独立实践。
- [ ] 我能复现自己的测试或评估结果。
- [ ] 我没有把历史测试或 AI 实现写成自己的独立成果。
- [ ] 我的每个数据都有样本、口径和原始结果。
- [ ] 我能做 1 分钟介绍与 5 分钟演示。
- [ ] 我能回答项目链路、设计取舍和失败处理的追问。
- [ ] 我的到岗时间、出勤安排和实习时长明确。
