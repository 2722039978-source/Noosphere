### 操作状态与 Windows 进程

- 提案不修改文件；执行只接受保存的操作 ID、工作区及确定的内容。重复确认、跨工作区确认及项目重新绑定均被拒绝。
- 已有文件修改和新建文件支持恢复；执行/恢复前检查哈希，拒绝覆盖外部改动。缺失或 null 的 `new_text` 被拒绝，避免不明确的删除意图。
- 待审批记录重启后保留；进行中记录变为中断，不自动重放。保存原文和实际文件共同决定可否恢复。
- 服务使用模拟适配器验证原状态冲突、启停结果及恢复原状态；未操作真实 Windows 服务。
- 使用真实 Windows 临时辅助进程验证 32 KiB 输出上限、移除本地 API 凭据环境变量及取消派生子进程。子进程先挂起创建、加入 Job 后恢复执行，关闭/取消时清理子进程。

### 审批界面

新增 4 组测试覆盖开启提案模式不自动批准、完整文件预览、冲突后刷新、逐项执行与恢复、固定测试提示/停止，以及服务提案重开后保留且不自动执行。聊天和任务中心读取后台真实操作记录，导入的聊天文字不能自行批准操作。

### 审查与回归修复

同一独立审查者在首次配额中断后恢复并完成审查。发现并修复一项日志恢复问题：小于 64 KiB 的 HTML 文件，保存前后内容经过 JSON HTML 转义后可能超过读取上限，导致重启时整个操作服务不可用。

回归先复现失败，再改为不做 HTML 转义、写入前执行与读取一致的大小限制，并在提案阶段为后续状态和错误预留 8 KiB。测试覆盖大量 `<&>` 文件的提案、执行、重启和恢复，以及控制字符编码膨胀的拒绝与接近上限的中断恢复。修复后全套 Go 测试与 vet 通过，独立审查者定向复核确认问题闭合，无遗留重要审查项。其他修复包括输出缓冲区绕过限制、必填替换文本及网络错误后的权威状态刷新。
