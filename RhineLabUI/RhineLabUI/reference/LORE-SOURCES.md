# 档案内容与设定来源

40 份正文为原创的档案式改写，研究记录中包含围绕设定提出的观察重点，并非游戏原文、官方实验结论或真实世界研究建议。编号仅用于本站编目。未核实的日期改为“跨期资料汇编”；人物字段标为“相关人物”，不虚构项目任命。卡片页及文本导出均保留对应来源。

核对重点：多萝西属于源石技艺应用科；斐尔迪南与能量科相关；结构科的研究内容不能与一般承重结构工程混同。事件和人物经历跨越多个阶段，避免把历史职务写成一律同时在任。
