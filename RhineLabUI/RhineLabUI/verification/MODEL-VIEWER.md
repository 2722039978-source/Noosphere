# 三维模型查看器验证

开发分支：feat/model-inspector；基于 69f9c99。

## 浏览器交互

- 从档案 X-001 的详情按钮进入查看器，模型和当前档案标签正常显示。
- 方向键右、上使视角目标从 (0,0,0) 移至约 (0.262,0.350,-0.268)；鼠标滚轮放大使观察距离由 14.501 降至 11.198。
- 鼠标拖拽越过侧面至方位角约 -3.143 弧度，实际检查了完整背面。Home 将视角、目标与距离恢复至默认值。
- 一键拆解后六组部件偏移分别为 2.75、1.85、0.75、-0.15、-1.1、-2.05，默认构图可看到全部部件，底部操作区可用。
- 一键重组后展开系数严格为 0，六组偏移全部回到 0；界面显示「已组装」。
- 展开系数约 0.290 时反向重组，保留连续运动并顺利归位。
- ESC 返回同一个档案 X-001，焦点恢复至入口按钮；再次打开可正常载入并操作。

## 自动检查

- scripts/check-assembly.mjs 验证六组部件、原始与装配资源的双向表面顶点距离、3.7 的模型高度，以及中途反向重组的连续性与收敛。
- 共检查 17,954 个原模型表面顶点，最大几何距离误差约 6.08e-7，低于 1e-5 容差。
- npm run build、scripts/check-assembly.mjs、scripts/check-appearance.mjs、scripts/check-motion.mjs 全部通过。构建保留既有的包体积提示。

透明部件使用现有实时透射材质，多个透明层间的递归折射仍受实时渲染能力限制。

## 光照一致性修订

- 修复两个 WebGL renderer 之间直接共享 PMREM 渲染目标纹理导致的环境光缺失；查看器独立生成与主场景相同的光照环境。
- 对照用户截图，实际检查组装正面、完整拆解、旋转和滚轮放大：内部基板、圆环和透明外壳均恢复浅色效果，拆解层次仍可辨认。
- 复用主界面的背景色与氛围渐变，雾效随模型观察距离调整。没有修改模型资源或材质颜色。
