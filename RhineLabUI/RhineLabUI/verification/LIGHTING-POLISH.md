# 基线动效与光影微调

用户确认回到原始基线 aeddd8f；本次保留循环阵列、独立查看器与数字滚动，主界面恢复有正负波谷、抬起与波浪同时开始的运动。

## 本次调整

- 阵列与独立查看器共用灯光配置，分别创建自身上下文的环境贴图。
- 主光转到前上方，降低补光和整体曝光，保留玻璃边缘反光与暖灰内部结构。
- 阵列盖板的斜面增加暖色吸收，背板改为浅香槟色；微调接触阴影与 AO。
- 透光吸收色、距离随材质质量连续插值，兼容不含吸收属性的普通不透明材质。
- 模型与相机轨迹不变。旧运动实验以明确标注的方式保留在 reference 页面。
